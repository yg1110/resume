현장 PC용 데스크톱 앱 재작성 (150MB → 10.9MB)

  • 웹 화면 하나를 전체화면으로 띄우기만 하는 앱인데 브라우저 엔진을 통째로 동봉해 설치 파일이 150MB + 부속 파일 다수. 정작 그 엔진의 기능은 거의 쓰지 않아, PC에 이미 설치된 웹뷰를 빌려 쓰는 방식(Go/Wails)으로 다시 작성
  • 10.9MB 실행 파일 하나 (약 93% 감소). 확대·새로고침·폴더 열기 버튼, 확대 배율 저장, 연결 상태 표시와 재시도 중단 조건 구현
  • 설치 관리자가 제거·업데이트 도중 공용 웹뷰 프로세스를 종료해 같은 PC의 다른 앱까지 꺼지던 문제, 다른 프로그램과의 실행 충돌, 작업표시줄 아이콘이 깨지던 문제 수정
  • 빌드·배포 파이프라인과 설치 파일 생성을 자동화해, 버전 태그만 올리면 릴리스가 만들어지도록 구성

🚀 Impact: 설치 파일 150MB → 10.9MB, 단일 파일 배포로 전환. 브라우저 엔진 보안 업데이트는 OS가 처리하게 됨
